## 📌 Notas rápidas / Glossário

| Termo | Significado |
|---|---|
| CI | Continuous Integration — integrar código com frequência |
| CD | Continuous Delivery / Deployment |
| IaC | Infrastructure as Code |
| MTTR | Mean Time to Recover — tempo médio de recuperação |
| SLA | Service Level Agreement |
| SLO | Service Level Objective |
| Pipeline | Fluxo automatizado de build → test → deploy |
| Shift-left | Detectar problemas mais cedo no ciclo |
