Azure Container Instances (ACI) e Container Registry (ACR)

Guia passo a passo explicado para implantar, gerenciar e executar aplicações containerizadas na nuvem Azure.

Sobre este material

Este documento reorganiza o conteúdo em formato de guia estruturado, detalhando a finalidade e a execução de cada comando do Azure CLI e do Docker.

Cenário Prático - Arquitetura da Aplicação

O sistema do projeto é composto por 3 microsserviços containerizados de forma independente:

Serviço Tecnologia Função
mysql-dimdimMySQL 8.0Banco de dados relacional para armazenamento de transações
api-dimdimJava / Spring BootAPI REST principal de comunicação com o banco de dados
api-transacoes.NET 8.0API REST secundária para processamento de transações
Objetivo do Exercício

Migrar os containers que rodavam localmente em docker-compose para uma infraestrutura Serverless pública na nuvem Azure, acessível via IP público ou FQDN.

1. Seu Computador / VM Build das imagens Docker a partir do código-fonte docker build
2. Imagem Local com Tag Etiquetamento com a URL do servidor do ACR docker tag
3. Azure Container Registry (ACR) Armazenamento privado e criptografado da imagem docker push
4. Azure Container Instances (ACI) Execução 24/7 Serverless com IP público ou FQDN az container create

3. Configurando o Azure Container Registry (ACR)

3.1 Autenticação e Grupo de Recursos

bashAzure CLI Setup
# Login na conta Azure
az login

# Verificar a assinatura ativa
az account show

# Trocar assinatura ativa (se necessário)
az account list -o table
az account set --subscription "nome-ou-id-da-assinatura"

# Criar Grupo de Recursos
az group create -l southafricanorth -n rg-money-hub

# Registrar o provedor do Container Registry (executar uma única vez)
az provider register --namespace Microsoft.ContainerRegistry

3.2 Provisionamento do ACR

bashCreate ACR
az acr create \
  --resource-group rg-money-hub \
  --name moneyhubrm(seu-rm) \
  --sku Standard \
  --location southafricanorth \
  --admin-enabled true
ParâmetroFinalidade
--resource-groupEspecifica o Grupo de Recursos onde o ACR será alocado
--nameNome globalmente único do registro (formato: nome.azurecr.io)
--skuNível de serviço e recursos (Basic, Standard, Premium)
--public-network-enabledHabilita acesso público via internet
--admin-enabledAtiva credenciais de usuário/senha administrador para autenticação simples

3.3 Extração de Credenciais e Login no ACR

bashACR Credentials
# Obter servidor de login
LOGIN_SERVER=$(az acr show --name moneyhubrm(seu-rm) --resource-group rg-money-hub --query loginServer --output tsv)
echo "Login Server: $LOGIN_SERVER"

# Obter usuário e senha do Admin
ADMIN_USERNAME=$(az acr credential show --name moneyhubrm(seu-rm) --resource-group rg-money-hub --query username --output tsv)
ADMIN_PASSWORD=$(az acr credential show --name moneyhubrm(seu-rm) --resource-group rg-money-hub --query passwords[0].value --output tsv)

# Autenticação A: via Azure CLI
az acr login --name moneyhubrm(seu-rm)

# Autenticação B: via Docker Login com credenciais
docker login moneyhubrm(seu-rm).azurecr.io -u $ADMIN_USERNAME -p $ADMIN_PASSWORD

3.4 Tagging e Push das Imagens

bashDocker Push
# 1. MySQL
docker tag mysql-dimdim moneyhubrm(seu-rm).azurecr.io/mysql-dimdim:v1
docker push moneyhubrm(seu-rm).azurecr.io/mysql-dimdim:v1

# 2. API Java
docker tag api-dimdim moneyhubrm(seu-rm).azurecr.io/api-dimdim:v1
docker push moneyhubrm(seu-rm).azurecr.io/api-dimdim:v1

# 3. API .NET
docker tag api-transacoes moneyhubrm(seu-rm).azurecr.io/api-transacoes:v1
docker push moneyhubrm(seu-rm).azurecr.io/api-transacoes:v1

# Confirmar os repositórios criados no ACR
az acr repository list --name moneyhubrm(seu-rm) --output table

# Limpeza opcional das imagens locais etiquetadas
docker rmi moneyhubrm(seu-rm).azurecr.io/api-transacoes:v1
docker rmi moneyhubrm(seu-rm).azurecr.io/api-dimdim:v1
docker rmi moneyhubrm(seu-rm).azurecr.io/mysql-dimdim:v1

4. Automação de Builds com ACR Tasks

Permite compilar e publicar automaticamente uma nova versão da imagem no ACR a cada novo commit realizado na branch principal do GitHub.

Observação Importante

ACR Tasks pode estar bloqueado ou indisponível em sua assinatura de ensino. Se o comando falhar com TasksOperationNotAllowed, use GitHub Actions como alternativa de automação.

bashACR Task Create
az acr task create \
  --registry moneyhubrm(seu-rm) \
  --name buildMySQL \
  --image mysql-dimdim:{{.Run.ID}} \
  --context https://github.com/SEU-USUARIO/mysql-dimdim-2.git#main \
  --file Dockerfile.mysql \
  --git-access-token SEU_TOKEN_DO_GITHUB \
  --commit-trigger-enabled true
bashACR Management Commands
# Listar tags de um repositório
az acr repository show-tags --name moneyhubrm(seu-rm) --repository mysql-dimdim

# Exibir manifesto técnico de uma imagem
az acr manifest list-metadata --registry moneyhubrm(seu-rm) --name api-dimdim

# Remover imagens sem tag com mais de 7 dias
az acr purge --name moneyhubrm(seu-rm) --filter "imagem:.*" --ago 7d --untagged

# Excluir a tarefa automatizada
az acr task delete --name buildMySQL --registry moneyhubrm(seu-rm) --yes

5. Publicação no Azure Container Instances (ACI)

5.0 Configuração dos Scripts (RM e Location)

Todos os 5 scripts abaixo vêm com os valores de exemplo rm=rm9999 (e, nos dois primeiros, location="eastus"). Em vez de abrir cada arquivo no nano e editar manualmente, rode o bloco abaixo uma única vez no mesmo diretório dos scripts: ele usa sed -i para substituir esses valores diretamente nos 5 arquivos.

bashEditar RM e Location nos Scripts
# 1. Defina o seu RM (mantendo o prefixo "rm") e a location desejada
MEU_RM="rm(seu-rm)"       # Exemplo: rm550000
MINHA_LOCATION="eastus"   # Altere se for usar outra region

# 2. Substitui automaticamente rm=rm9999 e location="eastus" nos 5 scripts
for script in 01_store-account.sh 02_key-vault.sh 03_aci-mysql.sh 04_aci-api-java.sh 05_aci-api-dotnet.sh; do
  sed -i "s/rm=rm9999/rm=$MEU_RM/" "$script"
  sed -i "s/location=\"eastus\"/location=\"$MINHA_LOCATION\"/" "$script"
done

# 3. Confirma que a troca foi aplicada em todos os arquivos
grep -H "^rm=" 01_store-account.sh 02_key-vault.sh 03_aci-mysql.sh 04_aci-api-java.sh 05_aci-api-dotnet.sh

5.1 Infraestrutura de Apoio (Storage & Key Vault)

bashProvisioning Scripts

# 2. Provisionar Key Vault para senhas e variáveis

./03_aci-mysql.sh > 03_aci-mysql.log

# Subir container da API Java

5.3 Inspeção e Conexão Interativa

bashACI Inspection
# Listar todos os containers
az container list --resource-group rg-money-hub --output table

# Logs de execução do container do MySQL
az container logs --resource-group rg-money-hub --name mysql-dimdim

# Conectar via cliente MySQL interno
az container exec --resource-group rg-money-hub --name mysql-dimdim \
  --exec-command "mysql -uuser-dimdim -psenha-dimdim"

# Obter FQDN público do container .NET
fqdndotnet=$(az container show --resource-group rg-money-hub --name api-dotnet \
  --query ipAddress.fqdn --output tsv)

# Obter IP público do container Java
ipjava=$(az container show --resource-group rg-money-hub --name api-java \
  --query ipAddress.ip --output tsv)

6. Homologação das APIs e Validação CRUD

bashHTTP Requests - CRUD Completo
# 1. Listar todas as transações (READ)
curl -X GET http://localhost:8080/api/transacoes

# 2. Criar nova transação (CREATE)
curl -X POST http://localhost:8080/api/transacoes \
  -H "Content-Type: application/json" \
  -d '{"descricao": "Compra no supermercado", "valor": 150.75}'

# 3. Atualizar transação (UPDATE via API .NET)
curl -X PUT http://$fqdndotnet:8080/api/transacoes/7 \
  -H "Content-Type: application/json" \
  -d '{"id": 7, "descricao": "Compra no supermercado - ALTERADO", "valor": 150.76, "dataTransacao": "2024-06-18T00:00:00"}'

# 4. Remover transação (DELETE)
curl -X DELETE http://localhost:8080/api/transacoes/8

# 5. Verificar resultado final
curl -X GET http://$fqdndotnet:8080/api/transacoes
