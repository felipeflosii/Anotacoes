## Indicadores de saúde do projeto

Atualize semanalmente:

| Semana | Tarefas planejadas | Tarefas entregues | Velocity |
|--------|-------------------|------------------|---------|
| 1 | | | |
| 2 | | | |
| 3 | | | |
| 4 | | | |

**Velocity** = tarefas entregues / tarefas planejadas × 100%
- Acima de 80%: saudável
- Entre 60–80%: atenção
- Abaixo de 60%: revisão urgente do escopo ou estimativas
