> O Lean Canvas é uma versão simplificada do Business Model Canvas, criada por Ash Maurya.
> É uma visão de uma página de todo o projeto ou negócio.
> Preencha em ordem: 1 → 2 → 3 → 4 → 5 → 6 → 7 → 8 → 9
> Nomeie como: `Lean Canvas - [Nome do Projeto] - v1.0`

## Preenchimento guiado — notas por bloco

### Bloco 1 — Segmentos de clientes
```
Quem é o público principal? (seja específico — não "todo mundo")
Ex: "Universitários de cursos noturnos entre 19-25 anos que trabalham e estudam"

Quem são os early adopters?
Ex: "Alunos da FIAP do curso de ADS do 3º período"
```

### Bloco 2 — Problema
```
Liste os 3 maiores problemas que esse público tem no contexto do seu projeto.
Baseie-se nas entrevistas de validação — não em suposições.

1. [problema mais crítico — causa mais dor]
2. [problema secundário]
3. [problema terciário]

Alternativas atuais (como resolvem hoje):
[O que usam mesmo que seja imperfeiro]
```

### Bloco 3 — Canais
```
Como as pessoas vão descobrir o projeto?
Como vão acessar?
Como o time vai distribuir?

Ex: Instagram da turma, indicação de professor, QR code na sala de aula,
    grupo do Discord da faculdade
```

### Bloco 4 — Solução
```
As 3 principais funcionalidades / entregas que resolvem os 3 problemas listados.
Uma por problema.

1. [solução para problema 1]
2. [solução para problema 2]
3. [solução para problema 3]
```

### Bloco 5 — Proposta Única de Valor
```
1 frase que responde: "Por que alguém usaria isso em vez das alternativas?"

Formato: [Verbo de benefício] + [resultado] + [para quem] + [sem o quê]
Ex: "Organize trabalhos em grupo sem precisar ser o chato que cobra os outros."
```

### Bloco 6 — Métricas-chave
```
Como vocês vão saber se está funcionando?
Escolha 2-4 indicadores mensuráveis.

Ex:
- Número de grupos criados na plataforma
- % de tarefas concluídas no prazo pelos usuários
- NPS (nota de 0-10 que os usuários dariam)
- Tempo médio de uso por sessão
```

### Bloco 7 — Estrutura de custos
```
Liste todos os custos reais do projeto.
Veja [[09 - Estrutura Financeira]] para detalhes.
```

### Bloco 8 — Fontes de receita
```
Como o projeto vai se sustentar financeiramente?
Para projetos acadêmicos: mesmo sem monetização, defina o modelo hipotético.
```

### Bloco 9 — Vantagem injusta
```
O que vocês têm que um concorrente não consegue copiar facilmente?

Ex: "Somos alunos do mesmo público que usaria — temos acesso e credibilidade naturais"
Ex: "Parceria com a coordenação que permite testar com turmas reais"
Ex: "Tecnologia proprietária desenvolvida durante o projeto"
```
