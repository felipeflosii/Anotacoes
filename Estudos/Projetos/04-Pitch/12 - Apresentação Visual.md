## A regra mais importante

> Um slide é um apoio visual para o que você está falando — não um teleprompter para ler.

Se a banca está lendo o seu slide, ela não está te ouvindo. Se você está lendo o seu slide, você parece despreparado.

---

## A estrutura de slides para um pitch completo (5–10 min)

| Slide | Título sugerido | Conteúdo |
|---|---|---|
| 1 | Capa | Nome do projeto + tagline de 1 frase |
| 2 | O Problema | 1 dado chocante + 1 frase que define a dor |
| 3 | Quem sofre | Persona + situação concreta |
| 4 | A Solução | 1 frase de posicionamento + imagem do produto |
| 5 | Como Funciona | 3 passos simples ou print do produto |
| 6 | Demonstração | Print / protótipo / QR code para testar |
| 7 | Mercado / Impacto | 1 número grande + SAM/SOM se for negócio |
| 8 | Diferenciais | Tabela: vocês vs alternativas |
| 9 | Time | Foto + 1 linha por pessoa |
| 10 | Próximos Passos | Chamada para ação clara |

## Regras de design para slides

```
📐 LAYOUT
✅ 1 ideia por slide
✅ Máximo 5 elementos visuais por slide
✅ Muito espaço em branco — respire
✅ Alinhamento consistente

🔤 TIPOGRAFIA
✅ Títulos: 36–48pt
✅ Corpo: 24–28pt (nunca menor — banca vê de longe)
✅ Máximo 2 fontes no deck inteiro
✅ Máximo 5 palavras por bullet

🎨 CORES
✅ 1 cor principal + 1 cor de destaque
✅ Fundo escuro ou claro — não misture
✅ Contraste alto para legibilidade

🖼️ IMAGENS
✅ Fotos reais do produto ou do público (quando possível)
✅ Ícones simples e consistentes
❌ Clipart, GIFs aleatórios, imagens de banco clichê
```
