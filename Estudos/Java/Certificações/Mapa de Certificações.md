```
FOUNDATION
═══════════════════════════════════════════════════════
  1Z0-811                    1Z0-819

  (iniciante, não técnico)   (Associate)
         │                        │
         └────────────┬───────────┘
                      ▼

═══════════════════════════════════════════════════════

         │
         ▼

```

| Certificação | Código | Nível | Ano sugerido | Custo (aprox.) |
|-------------|--------|-------|-------------|----------------|
| Java SE 21 Developer | 1Z0-829 | Associate | Ano 1–2 | USD 245 |
| Java SE 21 Professional | 1Z0-830 | Professional | Ano 3+ | USD 245 |

> [!tip] Dica sobre certificações Oracle
> O mercado valoriza mais projetos e experiência do que certificação Oracle. Priorize certificações de ecossistema (Spring, AWS, Kubernetes) que têm maior reconhecimento prático.
