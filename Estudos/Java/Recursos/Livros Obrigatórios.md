## Top 5 — Se só puder ler 5 livros na carreira inteira

1. ⭐⭐⭐⭐⭐ **Effective Java** — Joshua Bloch
   - Por que: Escrito pelo criador das Collections API e generics do Java. Cada item é uma lição prática com exemplos reais. Releia a cada 2 anos — você entenderá coisas diferentes.

2. ⭐⭐⭐⭐⭐ **Designing Data-Intensive Applications** — Martin Kleppmann
   - Por que: Explica como sistemas distribuídos realmente funcionam — bancos de dados, replicação, consistência, streams. O livro que te faz entender o "porquê" por trás de cada ferramenta.

3. ⭐⭐⭐⭐⭐ **Clean Code** — Robert C. Martin
   - Por que: Código é lido muito mais do que escrito. Este livro ensina a escrever código que outros (e você no futuro) conseguem entender.

4. ⭐⭐⭐⭐⭐ **Building Microservices** — Sam Newman
   - Por que: Se você vai trabalhar com microservices (e vai), este é o guia de referência. Cobre desde decomposição até comunicação, deploy e operação.

5. ⭐⭐⭐⭐⭐ **Staff Engineer** — Will Larson
   - Por que: Ninguém te ensina o que Staff Engineer faz. Este livro define o papel com exemplos reais de engineers de Google, Stripe, Slack, etc.
