## Por que a maioria das reuniões falha

Uma reunião falha quando:
- Não tem objetivo claro
- Pessoas erradas estão presentes
- Ninguém facilita e a conversa deriva
- Termina sem decisão ou próximo passo registrado

---

## Os quatro rituais essenciais

### Daily (10–15 min)

**Objetivo:** sincronização rápida, identificar bloqueios.

```
Formato:
1. O que fiz desde o último daily?
2. O que farei até o próximo?
3. Tem algum bloqueio?

Regras:
- Em pé ou com câmera ligada (mantém foco)
- Ninguém resolve problema durante o daily
  → "Vamos conversar depois"
- Facilita quem é Scrum Master / coordenador
```

### Planning de sprint (1–2h, a cada 1–2 semanas)

**Objetivo:** selecionar e estimar o trabalho do próximo sprint.

```
Pauta:
1. Review do sprint anterior (15 min)
2. Seleção das user stories do backlog (30 min)
3. Quebra em tasks e estimativa (30 min)
4. Distribuição entre o time (15 min)
```

### Retrospectiva (45 min, ao fim de cada sprint)

**Objetivo:** melhorar como o time trabalha.

```
Formato Start/Stop/Continue:
- O que devemos COMEÇAR a fazer?
- O que devemos PARAR de fazer?
- O que está funcionando e devemos CONTINUAR?

Regra de ouro: sair com no máximo 1 ação concreta por pessoa.
```

### 1-1 (30 min, individual, quinzenal)

**Objetivo:** conversa privada entre coordenador/tech lead e cada membro.

```
Pauta sugerida:
1. Como você está se sentindo no projeto?
2. O que está funcionando bem para você?
3. O que está te travando?
4. O que eu poderia fazer diferente para te ajudar?
```

> 1-1 não é reunião de status. É espaço de confiança. Nunca use para cobrar entrega.
